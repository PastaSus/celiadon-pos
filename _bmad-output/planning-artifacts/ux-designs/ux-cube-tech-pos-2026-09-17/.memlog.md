- (decision) Brownfield ratify - Tailwind 3.4 default palette, no theme.extend overrides. indigo-600 is the brand primary, gray-100 the page canvas, white the surface. DESIGN tokens reference the shipped component library, not a new design system.
- (constraint) Tailwind CSS only, no external UI library (SPEC constraint). Currency is USD only via formatCurrency from client/src/lib/api.ts - never the peso symbol.
- (decision) Existing component library is the UI system - Badge (5 tones), Button (6 variants x 3 sizes), LoadingSpinner, Modal, Table (typed Column generic plus dense mode), Toast (success/error/info, 4s auto-dismiss). EXPERIENCE.md carries the behavioral delta only.
- (decision) Component delta for the remaining capabilities - add SearchInput, FilterSelect, CartDrawer, StatCard, EmptyState, DateRangeBar, ReceiptView. Reuse Badge, Button, Table, Modal, Toast unchanged.
- (decision) Badge tones green/yellow/red/indigo/gray are canonical status colors. stockTone(quantity, reorderLevel) is the single stock-status rule - red at or below zero, yellow at or below reorder_level, green above.
- (decision) SPEC open question 2 answered - the low-stock threshold is per-product products.reorder_level with DEFAULT 10, not a fixed global 10. stockTone is already parameterized so no rewrite is needed.
- (assumption) SPEC open question 1 - the receipt store name renders as the constant Cube Tech POS for now. Multi-store is a SPEC non-goal, so one exported constant keeps it swappable later without touching receipt layout. Confirm or reject.
- (decision) CAP-2 search and filter - case-insensitive name search debounced 200ms, combined AND with a category FilterSelect whose first option is All categories. Inventory filters through the API, the POS grid filters client-side by category chips.
- (decision) CAP-3 payment method - segmented control in the POS checkout block, options cash, card, e-wallet, default cash, required before Complete Sale. Mirrors the sales.payment_method CHECK constraint and the PaymentMethod shared type.
- (decision) CAP-4 charts use Recharts, colored from the existing stat-dot palette (blue, green, purple, yellow) plus indigo-600 for the revenue series, so no new hex values enter the product.
- (decision) CAP-4 date range control - two native date inputs plus preset chips (today, 7 days, 30 days, 90 days). No date library added; ISO 8601 in the API, formatted for display in the client.
- (decision) CAP-4 dashboard surfaces four metric cards (total revenue, average transaction, today sales, low-stock count) above the charts, reusing the existing stat card layout.
- (decision) CAP-5 low-stock alert surfaces as a Dashboard callout card listing affected products, plus yellow and red Stock badges on Inventory and POS.
- (decision) CAP-5 stock movements is a filterable table page - product, type, signed quantity, reason, user, timestamp - reachable from nav for admin and manager.
- (decision) CAP-6 receipt - a dedicated print view plus print media rules in index.css, browser print dialog only, no PDF library. The receipt uses font-mono at an 80mm-friendly width and hides all app chrome when printing.
- (decision) CAP-9 is an app-wide rule set, not a story - md (768px) is the collapse breakpoint. Below md the nav becomes a hamburger drawer and the user meta hides. Below lg the POS cart leaves the 3-column grid and becomes a slide-out drawer with a fixed bottom summary bar. Tables scroll horizontally (Table already wraps in overflow-x-auto). Stat and chart grids stack to one column.
- (decision) IA additions - Reports (admin, manager) and Stock Movements (admin, manager) become nav items. Category management is a modal surface on Inventory, not a new page. The cashier nav stays Point of Sale plus Transactions.
- (decision) Accessibility floor - 2px indigo-500 focus ring on every interactive element, htmlFor-linked labels (the Inventory inputs are currently unlinked and must be fixed), Escape closes Modal, the toast container announces via role=status, and the printable receipt is reachable by keyboard.
- (decision) Voice is matter-of-fact retail counter - sentence case, no exclamation marks, no emoji in system messages, and money always rendered through formatCurrency.
- (version) Stack bound by this UX contract - Tailwind 3.4 default palette, React 18.3, react-router-dom 6.26, Recharts 2.x to be added, no date library and no PDF library.
